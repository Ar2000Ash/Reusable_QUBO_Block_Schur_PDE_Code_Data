\paragraph{New fixed-scale validation protocol.}
We independently reran the five benchmark systems using the nominal scales
$\gamma=0.60$ for Heat and Burgers, $\gamma=0.01$ for Poisson and Helmholtz,
and $\gamma=1.00$ for Klein--Gordon. All cases use $B=2$, $M=1$, $K=10$
(24 binary variables per inverse-column problem), and the PDE grids,
time increments, final times, manufactured forcing, and Dirichlet traces
specified for the fixed-validation benchmarks. A Schur block is constructed
from the previously decoded approximate inverse. Each inverse column receives
one exact finite-grid least-squares solve followed by exactly three residual
correction solves. The same nominal $\gamma$ is used for every block, column,
and stage, without an adaptive bound, shrink factor, or continuous correction
used to choose the scale. An independent CPU exact oracle minimizes the
2-scalar grid objective using conditional convex quadratic minimization.
The full 24-bit logical search space contains $2^{24}$ states, but the CPU
implementation does not enumerate all those states. Hence the timings in the
original GPU experiments are not reused or represented as new measurements.
The original historical measurements remain separately archived.

% Replace the results prose immediately following Figure 3 and its Table 3 by:
The new fixed-scale benchmark yields relative final-state errors of
$1.77\times10^{-2}$ (Heat), $9.82\times10^{-3}$ (Burgers),
$1.33\times10^{-3}$ (Poisson), $3.57\times10^{-3}$ (Helmholtz), and
$1.90\times10^{-2}$ (Klein--Gordon). The largest local inverse residual is
$2.07\times10^{-3}$, for Helmholtz. All five cases use 80 or 160 exact
finite-grid column solves according to the number of unknowns.
Importantly, the three fixed-grid residual solves produce zero updates in
all benchmark columns: after the initial exact minimizer, the existing
lattice admits no better nonzero correction in these experiments. Thus the
reported factors have the same accuracy as one initial exact solve, and the
repeated steps add computation without improving the cached factors.
Reducing the correction scale or changing its range is necessary to access
smaller corrections; that constitutes a different protocol. The present
fixed-scale data are a controlled baseline, not evidence of refinement gains.

% Add to the limitations discussion:
The fixed-scale rerun exposes a practical limitation of residual refinement:
reusing an unchanged quantization grid can make all subsequent correction
QUBOs return the zero vector. The three added exact solves per column did
not improve accuracy in this benchmark. A refined or adaptive grid may
resolve smaller residuals, but must report the exact scale-selection rule and
its classical costs. Unlike the lost historical auto-bound experiment, the
new fixed-scale data and per-stage bitstrings are generated from archived
PDE specifications by a public, separately tested source driver. GPU
enumeration and speed comparisons are not claimed for the new run.
