# Pre-correction archive (read-only provenance)

These four CSV files are the exact text snapshots of the first public package's
inconsistent derived decoded-vector/residual fields. They are NOT authoritative
scientific results. The corrected operational files remain in `data/raw/dirac3/`
and `data/processed/`. Original bitstrings, job IDs, submitted QUBO energies,
sample counts and normalized objective gaps are unchanged by this repair.

Do not use these legacy files in analyses. See `docs/DIRAC3_DECODING_CORRECTION.md`.
