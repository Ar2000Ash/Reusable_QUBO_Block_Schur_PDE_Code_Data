# Data dictionary

This note lists the most important files rather than every column in every CSV.

## Convergence study

`data/raw/k_sweep/k_sweep_results.csv`
: One row per PDE and fractional-bit count K. Contains solution error, Schur-inverse
  error, minimized QUBO energy, residuals, candidate counts, and resource diagnostics.

`data/raw/k_sweep/convergence_slopes.csv`
: Fitted log2 slopes reported in the study.

## Five-PDE validation

`data/raw/fixed_validation/summary.csv`
: Cross-PDE summary used to populate the fixed-validation table.

Each PDE subdirectory contains:

- `config.json` - exact numerical settings used for that archived run;
- `diagnostics.json` - final errors, conditioning, inverse residuals, call counts, and enumeration counts;
- `solution_qubo_cached.csv` - final solution produced with cached QUBO-derived inverse factors;
- `reference_precise_numerical.csv` - dense numerical reference;
- `reference_analytical_or_manufactured.csv` - analytical/manufactured reference where applicable;
- `time_history.json` - retained only for time-dependent cases.

## Large-block study

`data/raw/large_block/largeB_poisson_lineblock_summary.csv`
: B, logical bits, dense QUBO coefficient count, representability/clipping diagnostics,
  conditioning, solution error, and PDE residual for N=960.

## B=8 optimizer study

`representative_optimizer_instances.csv`
: Per-instance results for the 32 representative 96-bit QUBOs and four strategies.

`optimizer_summary_by_method.csv`
: Method-level summary used in the reported analysis.

`full_greedy_polish_all_inverse_columns.csv`
: Per-column changes over all 960 inverse columns.

`full_cached_solve_summary.csv`
: Downstream Poisson solution error and PDE residual before/after greedy polishing.

## Dirac-3 hardware study

`returned_samples.csv`
: Sample-level stored hardware outputs with bitstrings, counts, energies, decoded values,
  residuals, and exact-hit indicators.

`unique_jobs.csv`
: One row per unique hardware submission, including job ID, schedule, sample count,
  metered device usage, best returned state, and exact-reference comparison.

`mapped_60_instances.csv`
: The 60 mapped PDE inverse-column instances used for the hardware audit.

`heat_solution.csv`, `poisson_solution.csv`,
`klein_gordon_solution.csv`
: End-to-end PDE fields used in the final reconstruction plots.

## Processed analysis inputs

`data/processed/` is regenerated by `analysis/build_processed_data.py`. These CSVs are
small deterministic analysis tables used by the verification and figure-generation scripts.
